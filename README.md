# Govind Yadav — Cloud Infrastructure Engineering Portfolio

A static personal engineering website for Govind Yadav, focused on cloud infrastructure, infrastructure as code, Linux systems, containers, and deployment automation.

## Stack

- Semantic HTML5
- Modern CSS with design tokens
- Minimal vanilla JavaScript
- Inline SVG infrastructure diagrams
- No build step or framework

## Local development

```bash
cd govind-infrastructure-portfolio
python3 -m http.server 8000
```

Open http://localhost:8000

## GitHub Pages deployment

1. Create a new public repository named `govind-infrastructure-portfolio`.
2. Push this folder’s contents to that repository’s `main` branch.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then save.
6. The site will be available at:

https://govind-yadav-IT.github.io/govind-infrastructure-portfolio/

The site uses only relative asset and page links, so it works correctly as a GitHub Pages project site.

## Content accuracy

Project case studies use supplied repository information. Features that could not be independently verified from the repositories are explicitly marked as needing verification rather than presented as confirmed implementation details.

About

Engineering the layer beneath the application

I am Govind Yadav, an early-career engineer based in Mumbai, developing practical capabilities in cloud infrastructure, infrastructure as code, Linux systems, containers, and deployment automation.

What draws me to infrastructure engineering is the layer beneath the application. A website or service appears simple from the outside, but it depends on compute, networking, storage, configuration, deployment pipelines, and operational checks. I enjoy understanding those dependencies and making them explicit.

My direction

My current direction is Cloud Engineering → Infrastructure Engineering → Platform Engineering. I am building from first principles: provisioning cloud resources with Terraform, hosting containerized services with Docker and Nginx, automating delivery with GitHub Actions, and using Bash to inspect and operate Linux systems.

I prefer learning by building small, inspectable systems. Rather than treating tooling as a black box, I try to understand what each command changes, what state it creates, and how a failure would appear.

How I learn

  • Build a focused project around one infrastructure concept.
  • Read the configuration and scripts closely enough to explain every major decision.
  • Use version control and CI checks to keep work reviewable.
  • Document objectives, limitations, and possible improvements honestly.
